CORS Attack Panel

1. Target

Vulnerable API

2. CORS Finding

Origin tested: null
Server response:
Access-Control-Allow-Origin: null
Access-Control-Allow-Credentials: true

Finding: The server trusts the null origin.

3. Payload

Payload used by the attacker to request the account API from a sandboxed context.

4. Attack Flow

  1. Identify that null is trusted.
  2. Create the malicious payload.
  3. Place the payload in malicious.html.
  4. Send the fake email containing the malicious link.
  5. Victim opens the link while logged in.
  6. The sandboxed iframe generates Origin: null.
  7. The vulnerable API processes the request.
  8. The result is sent to the attacker server.
